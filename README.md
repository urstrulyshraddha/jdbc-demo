# University AuthPortal — Java Swing & MySQL JDBC Demo

A clean, self-contained desktop authentication application demonstrating **Java Database Connectivity (JDBC)**, **MySQL Server** integration, and **Java Swing/AWT** UI synchronization. Built as a practical walkthrough for Advanced Java Programming.

---

## Project Structure

```text
auth-demo/
├── lib/
│   └── mysql-connector-j-8.4.0.jar   # MySQL JDBC Driver
├── bin/                              # Compiled .class bytecode (auto-generated)

├── auth_app.java                     # Main Swing GUI (Register, Login & Live JTable)
